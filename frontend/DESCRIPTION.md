# NorthPay · HR Tech / Global Payroll

## Vertical

Web App Development
## Sector

- Sector Fintech
- HRTech
## Descripción General

#### Problema

Centralize contractor onboarding in a web portal that reduces activation time to less than 3 days, eliminates the dispersion of channels, and provides the internal team with operational visibility into the status of each process.

#### Descripción

NorthPay manages payments and compliance for remote contractors in multiple countries. Currently, the activation process for each new contractor occurs via email, offline forms, and WhatsApp. The average activation time is 12 days, 8 of which are spent on bureaucratic procedures. 

##### Expectations

A functional web portal with an onboarding flow of at least 5 steps: personal data, document upload, contract signing, payment method configuration, and identity verification. An administration panel for the operations team with real-time status updates for each contractor. Automatic notifications for each status change. 
###### Users

- New contractors who complete the process from their devices. 
- NorthPay internal operators who monitor and approve each stage. 
##### Workflow

Contractor accesses the portal via invitation link → completes each step sequentially → uploads required documentation → digitally signs the contract → configures the payment method → ​​remains in "pending verification" status. Operator views the list of active onboardings → reviews documentation → approves or requests corrections → contractor receives notification → the account is activated.
